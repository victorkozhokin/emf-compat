# EMF Compat: Immersive Melodies — Changelog

## 1.2.1

### Fixed

- An error while posing an illager's arms no longer makes EMF stop animating its model for the rest of the session

## 1.2.0

### Added

- Mobs keep their instrument pose too: zombies, skeletons, piglins and illagers play instead of being animated over by Fresh Animations. Setting: "Mobs with instruments"
- Vindicators and evokers now uncross their arms and hold the instrument while playing, with or without a resource pack
- Added a Fabric 1.21.1 build

### Dependencies

- Requires EMF Compat Core 2.3.0

## 1.1.0

### Added

- Added a config tab

### Changed

- Instrument poses hold up better while you move
